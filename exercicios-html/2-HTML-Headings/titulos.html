Meu Livro sobre HTML

O h1 deve representar o assunto principal da página. Ele é o título mais importante e deve ser usado normalmente uma vez para identificar o tema principal.

Capítulo 1 - Introdução ao HTML

O HTML é utilizado para estruturar o conteúdo de páginas da web.

1.1 - O que é HTML?

HTML significa HyperText Markup Language e utiliza elementos para organizar textos, imagens, links e outros conteúdos.

1.1.1 - Estrutura de uma página

Uma página HTML possui elementos como html, head e body.

1.1.1.1 - Elementos importantes

Alguns elementos importantes são títulos, parágrafos, listas e links.

1.1.1.1.1 - Observação

Os títulos menores devem ser utilizados para organizar assuntos cada vez mais específicos dentro da estrutura da página.

Capítulo 2 - Títulos HTML

Os títulos HTML vão de h1 até h6 e possuem diferentes níveis de importância hierárquica.

2.1 - Hierarquia dos títulos

O h1 representa o nível principal, enquanto h2, h3, h4, h5 e h6 representam níveis progressivamente mais específicos.

2.1.1 - Organização do conteúdo

Uma boa hierarquia facilita a leitura e a compreensão da página.

2.1.1.1 - Exemplo prático

Podemos organizar uma página como se fosse o sumário de um livro, usando capítulos, seções e subseções.

2.1.1.1.1 - Fim do exemplo

Assim, os seis níveis de títulos podem representar diferentes níveis de organização do conteúdo.
